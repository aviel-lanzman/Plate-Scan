# Product demo video

A 37-second vertical (1080x1350) demo of the app for LinkedIn, in Hebrew,
without audio. Rebuild it with:

```bash
video/build.sh   # writes video/remotion/out/platescan-demo.mp4
```

How it is made:

| Part | Tool | Where |
|---|---|---|
| Intro and outro (kinetic type, app icon) | HyperFrames | `hyperframes/index.html`, `hyperframes/compositions/outro.html` |
| Scanning, result and continuous-scan scenes, transitions | Remotion | `remotion/src/` |
| The result screen inside the phone | The real app, rendered by a Flutter widget test with demo data | `flutter_shots/screens_test.dart` |
| The car in the camera and in the scan photos | A synthetic SVG drawing | `remotion/src/components/CarScene.tsx` |

The demo plates (98-765-43, 98-765-41, 987-65-432) are in none of the
data.gov.il datasets, so the video shows no real vehicle. The font is Heebo
(SIL Open Font License, `assets/fonts/OFL.txt`).

Everything under `remotion/public/` and `hyperframes/renders/` is generated by
`build.sh` and not committed.

Remotion is free for individuals and companies of up to three people; larger
companies need a licence (https://www.remotion.dev/license). HyperFrames is
Apache-2.0.
